# Vault 9 Fashion

Vault 9 Fashion is a responsive landing page designed to showcase a modern fashion brand. It features overlapping hero images with text overlays, dynamic image transitions, and a mobile-friendly carousel for smaller screens.

## How to Open / View

To view the project:

1. **Download or Clone the Repository:**  
   Ensure you have the full project files, including the HTML, CSS, and JavaScript.

2. **Open the `mini_projct` File:**  
   Simply double-click the `mini_projct` file (or the main HTML file in your project) and open it in your preferred web browser.  
   Alternatively, you can use a local server setup (e.g., using the Live Server extension in VS Code from the command line) for the best experience.

3. **Resize for Responsive Testing:**  
   The site is designed with responsive behavior. Resize your browser window or open the page on different devices to see the adjustments (e.g., the overlapping image effects on desktop versus the mobile carousel).

## Tools and Technologies Used

- **HTML5:**  
  Provides the semantic structure of the webpage.

- **CSS3:**  
  - **Media Queries:** Used for creating a responsive design that adjusts layouts based on the viewport.
  - **Transitions & Animations:** Enable smooth fading, blurring, and swapping effects for images.
  - **CSS Custom Properties:** Manage dynamic rotation angles for images, adjustable according to screen size.

- **JavaScript:**  
  Implements dynamic behaviors such as:
  - Fading and swapping overlapping images.
  - Cycling through images in the mobile carousel.

- **Remix Icon:**  
  An icon library used to display navigation and footer icons. It’s loaded via a CDN.

## Setup & Customization

1. **Clone the Repository or Download the Files:**
